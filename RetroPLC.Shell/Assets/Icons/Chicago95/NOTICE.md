# Chicago95 icon attribution

The PNG icons in this directory are selected, renamed copies from the Chicago95
icon theme by grassmunk and contributors:

https://github.com/grassmunk/Chicago95

The upstream project states its licensing as GPL-3.0+/MIT. Only a curated set of
16x16, 24x24, and 32x32 icons is included here; no upstream symlinks or unrelated
theme files are bundled.
