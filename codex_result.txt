gRPC and workspace discovery
  GetWorkspaceInfo probes startup readiness and exposes manifest metadata.
  ValidateWorkspace supplies the workspace root and confirms the manifest's
  Zephyr project is checked out before firmware preparation.
  GetProjects and GetWestConfig expose typed west project and configuration data.
  Grpc.Tools generates the C# bindings. Struct conversion and error mapping
  stay inside the backend integration. The five former RPCs remain wire
  compatibility stubs that return UNIMPLEMENTED. BuildHost never invokes them.
  The managed AC6 Python process remains lazy, shared, cancellable, and
  loopback-only, with the existing readiness timeout and shutdown ownership.
  West manifest loads are serialized because its schema validator has shared
  state. The backend uses documented west APIs for all workspace metadata.
  setup.sh verifies the new west dependency alongside the gRPC imports.
  Installed west 1.5.0, grpcio 1.85.3, and protobuf 6.33.6 met the requirements.

Configuration, boards, SDK, and builds
  ResolveAsync merges operation, project, IDE, environment, and built-in
  settings locally. It preserves project and installation path bases, CMake
  option merging, the project JSON shape, sysbuild, and pristine settings.
  Terminal launch uses AC6 directly. Local configuration, terminal, and
  clean operations do not need the Python backend.
  Board targets are opaque strings. The default remains
  arduino_opta/stm32h747xx/m7. Board API compatibility methods explicitly
  report unsupported discovery and prevalidation. There is no live board picker.
  BuildHost checks that the selected SDK directory exists. It supplies the
  flat SDK path and toolchain variant to AC6 west and CMake, including the
  existing sysbuild options. Zephyr's CMake determines compatibility.
  Removed hand parsing of CMakeCache.txt. West handles pristine modes.
  Rebuild uses always. Clean removes the project's Build tree as before.
  Structured Text compilation, generated-source paths, artifacts, verify,
  and mcumgr download remain in BuildHost. Failed processes leave diagnostic
  output in the Build tool and the UI status points to that output.

  the zephyr project, and manifest.path over gRPC. A temporary copy of TestProj

Limitations
  Use Rebuild to reset existing CMake state after changing SDK installations.
  The loopback port remains unauthenticated. Desktop interaction, physical
  firmware upload, macOS, and Windows were not exercised. Existing Shell
  threading analyzer warnings appeared on a full compilation.
