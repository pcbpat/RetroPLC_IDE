Python helper, packaging entry, and manager-only tests. Removed SDK installer,
global discovery, and saved selection logic from ZephyrSdkService. Rider's

building the solution. setup.sh's pre-existing changes were left untouched.

Provisioned paths and launch
- RetroPlcInstallation uses the existing application directory resolution.
  Published applications use the installation beside the executable. An IDE
  build resolves the solution root from its application directory. The current
  working directory is independent of this resolution.
- Defaults are .zephyr/workspace, its retroplc-runtime/app, the flat .zephyr/sdk,
  and board arduino_opta/stm32h747xx/m7. The attached .zephyr/folders.txt and
  live tree confirm gnu/arm-zephyr-eabi/bin/arm-zephyr-eabi-gcc in the flat SDK.
- Firmware startup checks managed west, .west/config, the Runtime CMakeLists.txt,
  zephyr/SDK_VERSION, sdk_version, the SDK CMake package, and the compiler.
  Existing project and per-operation overrides still resolve against the
  project. Explicit IDE and RETROPLC_* path overrides resolve against the
  application root. The inherited generic SDK setting is cleared for west.
- The existing AC6 launcher uses .zinstaller/.venv/bin/python and bin/west
  on Linux, sourcing env.sh and checking that CMake and Ninja resolve inside
  the AC6 tools tree. It sets WEST_CONFIG_LOCAL, ZEPHYR_SDK_INSTALL_DIR and
  ZEPHYR_TOOLCHAIN_VARIANT=zephyr in the west process.
- Default firmware stage runs from .zephyr/workspace:
  west build -p auto --sysbuild -b arduino_opta/stm32h747xx/m7
    -s <root>/.zephyr/workspace/retroplc-runtime/app
    -d <project>/Build/Zephyr/arduino_opta_stm32h747xx_m7 --
    -Dapp_RETROPLC_GENERATED_DIR=<project>/Build/Generated
    -DZEPHYR_SDK_INSTALL_DIR:PATH=<root>/.zephyr/sdk
    -DZephyr-sdk_DIR:PATH=<root>/.zephyr/sdk/cmake
  The full invocation also supplies BOARD, app_BOARD, app-scoped SDK paths,
  a cache marker for the actual SDK metadata version, and project CMake
  options. Verify, Clean, Rebuild, artifact publishing and mcumgr upload
  retain their existing entry points.
- Auto mode uses a pristine build when SDK path, package, version, or sysbuild
  mode changes. Never mode requires Rebuild for incompatible cached settings.
- Removed defaults for .zephyr/zephyr-workspace, .zephyr/sdks and
  RetroPLC_Runtime/app. Existing valid explicit directory settings are retained.
