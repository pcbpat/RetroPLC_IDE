Firmware download progress dialog

Download now opens a themed modal from the existing toolbar and menu command.
The dialog follows compilation, upload preparation, transfer, and subsequent
deployment steps. It calculates transfer percentage from NDJSON byte counts,
retains the last valid measurement when later steps omit counts, and reserves
100% for a successful terminal result and exit code 0. An already-installed
image is a success. Failure shows the available error message.

The Close button and window close requests are blocked during the operation.
Every terminal outcome enables closing, and the dialog stays open for review.
BuildHost still runs plc-build followed by plc-upload after a successful build.
Compiler output and diagnostics still go to the docked build output.
