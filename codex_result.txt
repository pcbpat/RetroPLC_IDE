Rebuild command

Added Rebuild beside Build in the Verify, Build, Rebuild toolbar sequence. It
uses the existing refresh icon and the "Rebuild Project" tooltip. The Build
menu has one Rebuild entry, bound to the same command as the toolbar. Build
and Rebuild share the project-open and build-idle checks.

BuildHost runs Verify via plc-transpile, incremental Build via plc-build,
pristine Rebuild via plc-rebuild, and Clean via plc-clean. Download uses
plc-build followed by plc-upload after successful artifact validation. Rebuild
uses the existing process, NDJSON, cancellation, and error handling and is
identified in the docked output and PLC status.
